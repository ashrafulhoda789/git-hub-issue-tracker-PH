## Question-1:
  ### var
    - Function scoped
    - can be reassign
    - can be redeclare
 ### let
    - Block scoped
    - can be reassign
    - cannot be reassign
 ### const
    - Block scoped
    - cannot be reassign
    - cannot be redeclare
## Question-2:
  - Spread operator used to expand element from array, object into individual elements.
  - By using spread operator we can copy and merging an array, add elements into array.
## Question-3:
  map():
    - It's used to transform each element of an array and return a new array.
  filter():
    - It's used to select elements that satisfy a condition and return a new array.
  forEach():
   - It's used to loop through an array and perform an action, but don't return a new array.
## Question-4:
  - An arrow function is a shorter syntax for writing function using (=>) operator. It was introduced in ES6.
  - Arrow function cannot be used as constructor
